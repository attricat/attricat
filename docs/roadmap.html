Internal planning roadmap, reviewed 2026-11-02

Attricat PIM / DAM foundations

The versioned EAV core is a sound PIM kernel, and most of the primitives this roadmap first called for now exist at least in part. This is where each one stands against the code, and what is still missing. 1.0 stabilizes what exists, so none of the gaps below are 1.0 commitments.

Design rule: add durable domain primitives before building product workflows on top of them. Hierarchical contexts, workspaces and channel publication now follow it; rights and richer renditions are the largest primitives left if DAM is a target.

Foundation

Implemented

Tenant and identity boundary

Workspaces, memberships and role grants scoped to a workspace, blueprint family, record or context subtree. People sign in with a password or the workspace's OpenID Connect provider.

Isolation is enforced in Rust application code; the database policy rules out row-level security policies.

Implemented

Context hierarchy and fallback

Contexts have parent_id, a persisted default root, and one deterministic inheritance path.

Resolved reads use nearest-ancestor wins and return the supplying context, so consumers can distinguish overrides from inheritance.

Partial

Audit and provenance envelope

Audit events carry actor, token, request and correlation IDs, agent attribution and before/after values.

Missing from audit rows: reason, effective timestamps, import job and idempotency key.

Partial

Record lifecycle and channel publication approval

Status control with approvals bound to a content digest, and publication approval per channel, separate from value history.

Missing: effective dates and scheduled publication. A channel reads live values, not a snapshot; editing a record withdraws its approval by default.

PIM primitives

Partial

Attribute constraints and cardinality

Requiredness, unique keys scoped to the workspace or a context, JSON Schema validation and relationship cardinality exist. Missing: ordered multi-value scalar collections.

Partial

Domain value types

String, number, integer, boolean, date, datetime, time, JSON, relationship and file, extensible through extension attribute types. Missing: measurement plus unit, and money. Rich text, enums and URLs are presentation or schema over strings.

Partial

Relationship semantics

Target cardinality, acyclic and tree constraints, and child scopes replacing the set exist. Missing: edge order, edge metadata, declared inverses and incremental inheritance.

Implemented

Business identifiers

Schema-declared unique keys, generated numbers, and lookup and upsert by business key. There are no built-in GTIN or SKU types.

Partial

Reference data

Enum labels, versioned reusable attributes, and taxonomies modeled as records with tree relationships, which the classification docs choose deliberately. Missing: units, and first-class versioned option sets.

Partial

Validation and computed values

A rules engine with per-rule context and channel-required checks. Missing: completeness per context and channel, and computed attributes in core; the example extension shows formulas can be built on the extension system.

Implemented

Record schema migration

Validated preview and migration between blueprint revisions, with projection rebuild, batches and impact reporting. Richer transforms remain future work.

DAM primitives

Partial

Asset aggregate and blob storage

Files with object key, SHA-256, MIME type, size, dimensions and state, attached through file attributes. Missing: duration, and managing files apart from records; unreferenced files are reclaimed.

Partial

Asset versions and renditions

Generated thumbnail, display, avatar and text variants. Missing: file revisions, configurable transforms, crops, focal points, transcoding and channel-specific selection.

Partial

Asset usage edges

File references have position and context. Missing: enforced roles, crop and focal-point metadata, and usage state.

Partial

Extraction and enrichment

Text extraction from PDF, Word and Excel files, plus basic technical metadata. Missing: EXIF beyond orientation, IPTC, XMP, OCR, transcripts, generated labels and confidence.

Partial

Rights and retention

Deletion with a grace period, status-based retention, explicit holds and deployment-wide retention settings. Missing: copyright, licenses, territories, rights expiry, embargoes, consent and rights-based restrictions.

Partial

Processing jobs

Upload and download contracts, retried jobs and observable status. Missing: deduplication, and malware scanning, which does not exist at all.

Platform and integration primitives

Not implemented

Declarative projections

Only the built-in preview exists, rebuilt during writes. Named, versioned projections and repair or backfill operations do not.

Partial

Context-aware query DSL

Typed filters, sort, relationship filters and facets, and explicit context selection. Missing: ranked full-text search (matching is trigram and ILIKE) and facets on scalar values.

Partial

Bulk import/export jobs

Connector jobs, idempotent checkpointed runs, dry runs and per-intent outcomes, through extensions. Missing in the engine: import staging, field mapping, validation reports and a partial-failure policy.

Partial

Outbox and change feed

A transactional outbox, retried deliveries with dead-letter replay, and a sequence-ordered feed for extensions. Missing: webhook delivery and a public change feed. Delivery order is not guaranteed.

Partial

Client concurrency contract

An optional expected_updated_at gives 409 stale_record, required for status edits. Missing: If-Match on writes, and idempotency on core record commands; runs have it.

Context hierarchy implementation notes

Implemented

One parent, named scopes

attribute_contexts.parent_id models a rooted tree. default is the protected sole root; every other scope has one parent and a stable human-readable code.

Implemented

Nearest ancestor wins

Resolved reads try the requested scope first and then each ancestor through default. Attributes with fallback disabled do not inherit.

Implemented

Protect inherited behavior

Reparenting rejects cycles. Deletion rejects contexts with descendants or current values.

Implemented

Expose the source scope

Resolved preview reads return both the requested context and the context that supplied each value, making overrides and inheritance explicit.
