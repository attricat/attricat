# Releasing

Attricat has one product version, `[workspace.package] version` in the root
`Cargo.toml`. Every crate inherits it, so the API's `/health` build info, the
binaries in the container image, and the standalone `acli` all report the same
version. Versions follow [Semantic Versioning](https://semver.org/); before
1.0, a minor release may break compatibility.

The `attricat:host` WIT ABI is versioned separately; see
[Host ABI versions and evolution](extensions.md#host-abi-versions-and-evolution).
A release that adds a host ABI version should say so in its notes.

## Cut a release

From an up-to-date, clean `main`:

```sh
just release minor   # or major, patch, or an exact version such as 1.0.0-rc.1
```

`scripts/release.sh` shows the commits since the last tag, asks for
confirmation, then bumps the workspace version, commits `Cargo.toml` and
`Cargo.lock` as `Release vX.Y.Z`, creates an annotated `vX.Y.Z` tag, and pushes
`main` and the tag together.

Choosing the bump is a judgement call. Treat these as breaking: removing or
changing API routes or response fields, configuration changes operators must
act on, migrations that cannot run against a live older version, and changes
to blueprint, manifest or other `contracts/` formats that existing files no
longer satisfy.

## What the tag publishes

- **Container image** (`.github/workflows/ci.yml`, `release-path`): rebuilds and
  verifies the image, checks that the tag matches the workspace version, and
  pushes `ghcr.io/attricat/attricat:X.Y.Z` and `:X.Y`, plus `:X` from 1.0.
  Pre-releases get only their exact tag. `latest` keeps following `main`.
- **`acli` binaries** (`.github/workflows/release.yml`, generated by
  [cargo-dist](https://opensource.axo.dev/cargo-dist/)): builds `acli` for
  Linux, macOS and Windows, and creates the GitHub Release with the archives,
  checksums and shell/PowerShell installers.
- **Release notes** (`.github/workflows/release-notes.yml`): runs after the
  release is published and fills it with GitHub's generated notes since the
  previous tag.

`release.yml` is generated. Change `dist-workspace.toml` (or
`[package.metadata.dist]` in `apps/cli/Cargo.toml`) and run
`dist generate` instead of editing it; `dist plan` previews the artifacts.
